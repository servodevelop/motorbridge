03协议实现与统一数据映射

CAN：完整寄存器访问链路

  • 经典 CAN 标准帧，仲裁 ID 为 0x321，数据区携带 ServoID。
  • 实现单寄存器及双寄存器读写，组合多圈角度、序号等 32 位参数。
  • 实现运动参数块 0x50–0x59 的原始读写，覆盖时间、目标角度、功率、加减速时间、速度与执行控制。
  • 提供阻尼功率、圈数重置、原点及参数复位的寄存器操作入口。
  • 受保护 PID 区域 0xC8–0xD5 的访问由驱动完成解锁、操作与复锁。

UART/RS-485：原生串口协议链路

  • 使用 transport=uart、8-N-1 和显式串口波特率；SDK 创建入口默认 115200。
  • 实现请求/回应帧、长度检查、累加校验、分包组包及噪声重同步。
  • 原生 0x0F 位置命令携带速度上限；加速和减速时间均为协议下限 20 ms，执行功率使用设备配置上限。
  • 原生 0x16 监控回包集中提供位置、电流、温度、状态等数据。
  • 同一控制器下的总线事务串行执行，发送间隔至少 5 ms；低波特率时根据请求与回应长度增加间隔，回复按命令、ServoID、参数地址和长度匹配。

统一状态：应用直接使用物理单位

应用字段交付含义处理方式
pos多圈位置 / rad解析有符号多圈角度，将协议中的 0.1° 单位换算为弧度。
vel估算平均速度 / rad/s按 Δ位置 ÷ Δ时间 计算；从第二次连续有效采样起提供估算值，查询中断或置零后重新建立采样基线。
torq电流 / A读取电流原始值 mA，除以 1000 后映射至统一字段；驱动内部字段名为 current_a。
t_mos舵机温度 / °C按官方工具采用的 NTC 参数将 ADC 换算为摄氏度：B=3435、参考温度 298.15 K、ADC 满量程 4096。
status_code设备状态字保留设备反馈的状态编码，便于应用层按协议识别运行状态。
快照元数据更新序号、数据时效完成整组状态查询后更新快照，复用 motorbridge 的反馈序号与数据年龄接口。

电压、功率、圈数和单圈角度通过参数读取与 WS 参数流提供；位置、电流、温度、状态和估算速度进入统一电机状态接口。

04接口交付与接入方式

接入层本次交付的入口与能力
Rust 驱动与 CLIFashionstarController、FashionstarMotor；命令覆盖 scan、ping、status、enable、disable、stop、pos-vel、zero、read-param、write-param，并支持 --set-motor-id。
C ABI新增 motor_controller_add_fashionstar_motor 与 motor_controller_new_uart；复用位置控制、反馈、状态、参数和生命周期函数。
Python SDK / CLIController.add_fashionstar_motor(...)、Controller.from_uart(...)；SDK 复用电机方法，CLI 接入扫描、改 ID、位置控制、使能/卸力、置零、型号查询与参数读写。
C++Controller::add_fashionstar_motor(...)、Controller::from_uart(...)；复用 Motor 对象完成控制、状态及参数操作。
WebSocket接入 set_target、scan、verify、set_id、pos_vel、state_once、状态流及 param_stream；参数流沿用统一编号。

连接参数与操作入口

CAN

使用已配置的 CAN 通道，feedback_id=0x321，motor_id 为设备 ServoID。

motor_cli --vendor fashionstar \
  --model fashionstar --transport socketcan \
  --channel can0 --motor-id 0 --mode status

UART / RS-485

显式指定 transport=uart 和匹配的串口波特率；feedback_id=0x321 用作统一接口占位值，设备通过 ServoID 寻址。

motor_cli --vendor fashionstar \
  --model uart --transport uart \
  --serial-port /dev/ttyUSB0 \
  --serial-baud 115200 --motor-id 0 \
  --mode status

统一配置操作流程

  1. 识别设备选择链路，扫描 ServoID，读取型号和当前参数。
  2. 写入配置使用公共参数编号设置 ID、通信速率或运行配置。
  3. 应用配置CAN 重新上电；UART 的 ID 和波特率立即切换。
  4. 回读确认使用新连接参数重新识别设备并核对目标配置。
